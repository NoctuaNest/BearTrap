
# BearTrap

 BearTrap is a DLP Honeypot, meant to disguised as a important file and stolen in the event of a intrusion. After activation it first searches for a key on the machines computer, this key is used for Friend or Foe identification to confirm its on a unrecognized device. After confirming its been stolen, it will give the attackers IP and device information to the defenders, then attempt to delete any other stolen data.
